# BULKA — навчальний сайт бренду екоіграшок

## Як відкрити на Windows
1. Завантажте ZIP-файл.
2. **Обов’язково натисніть правою кнопкою на ZIP → «Видобути все…» (Extract All).** Не запускайте сторінки прямо всередині ZIP-архіву.
3. Відкрийте розпаковану папку `BULKA-website`.
4. Двічі натисніть `index.html`. У браузері з’явиться головна сторінка.
5. Інші сторінки відкриваються через меню. Навіть без JavaScript усі сторінки показують основний контент.

## Як опублікувати на GitHub Pages
1. Створіть **публічний** репозиторій на GitHub.
2. Завантажте **вміст** папки `BULKA-website` (файл `index.html`, інші HTML-файли, папки `css`, `js`, `images`) **у корінь репозиторію**, не додатковою вкладеною папкою.
3. Відкрийте Settings → Pages → Build and deployment → Deploy from a branch.
4. Виберіть `main`, `/(root)` і Save.
5. Дочекайтеся публікації. URL матиме вигляд `https://USERNAME.github.io/REPOSITORY/`.

## Важливо
Це навчальний проєкт. Кошик використовує localStorage браузера. Форми та оплата демонстраційні; дані не надсилаються на сервер. Зображення іграшок і відгуки є демонстраційними. Вимоги до безпечності іграшок і характеристики матеріалів потрібно перевірити перед реальними продажами.
